# 브라우저 시안 검증 기록

검증일: 2026-10-15

## 검증 대상과 실행

대상은 [독립 HTML 시안](../../preview/index.html)이다. [도구 막대와 입력 설계](interaction-design.md)의 브라우저에서 확인 가능한 부분을 검증한다. 데스크톱 앱 구현 완료 판정과 구분한다.

`preview/index.html`을 브라우저에서 직접 열거나, 프로젝트 루트에서 다음 명령으로 로컬 서버를 실행한다.

```sh
python3 -m http.server 4218 --bind 127.0.0.1 --directory preview
```

서버 실행 후 [로컬 시안](http://127.0.0.1:4218/)에 접속한다. 서버는 `preview` 폴더만 제공한다. 외부 라이브러리나 네트워크 API 없이 동작하도록 구성한다.

## 검증 범위

브라우저의 실제 포인터·키보드 입력으로 오브젝트 생성, 편집, 속성 변경, 삭제·취소, 단축키 설정을 확인한다. 도형의 교차 경계는 구체적인 기하 사례도 함께 확인한다. 데스크톱 크기와 360px 폭 화면을 캡처해 배치를 살핀다.

브라우저에서 합성한 조합 이벤트는 입력 분기만 검사한다. 실제 macOS·Windows 한글 IME의 조합·후보 선택은 각 OS에서 별도 검증해야 한다.

## 실행 결과

Chrome 155.0.8059.40의 격리된 headless 브라우저에서 Playwright CLI 0.1.18로 실행했다. 화면 크기는 1280×900과 360×800이다. **43개 조건 모두 통과**했으며 [개별 결과 JSON](../../output/playwright/verification-results.json)을 보관했다.

| 구분 | 수 | 확인한 내용 |
|---|---:|---|
| 교차 계산 사례 | 17 | 2 DIP·0 면적 제외, 길고 얇은 영역, 역방향, 선·점·둥근 끝·사각형 테두리·텍스트 경계, 빈 경계 상자·빈 사각형 내부 제외 |
| 브라우저 입력·상태·배치 | 26 | 필기·사각형 속성, 제스처 도중 도구 변경, 텍스트 생성·기존 크기 편집·취소·외부 클릭 소비, 단축키 중복·저장·취소·새로고침 복원, 혼합 오브젝트 삭제·취소·숨김 복원, 좁은 화면 배치 |

두 번째 묶음에는 합성 IME 조합, `blur`, `pointercancel` 이벤트를 주입한 분기 검사 3개가 포함된다. 한글 여러 줄 텍스트를 입력해 표시·편집했지만 실제 한글 입력기의 조합·후보 선택까지 수행한 검증은 아니다.

펜·사각형·텍스트 3개를 삭제 영역에 걸치게 만들고, 드래그 중 원본이 유지되는 것과 버튼 해제 후 세 오브젝트가 함께 사라지는 것을 확인했다. 삭제 중 Ctrl 해제, Escape, 합성 포커스 상실·포인터 취소, 숨김 토글 후 버튼 해제에서도 원본이 유지됐다.

검토 중 진행 중인 획이 도구 키 전환으로 취소되던 문제와 포인터 이동 샘플이 빈 경우의 처리를 보완했다. 위 43개 결과는 해당 보완 후 실행한 결과다. 화면 캡처도 열어 확인했다.

| 캡처 | 확인 |
|---|---|
| [기본 화면](../../output/playwright/my-brush-desktop.png) | 가로 도구 막대, 기본 샘플 필기·사각형·텍스트 |
| [삭제 미리 보기](../../output/playwright/my-brush-delete-preview.png) | 영역 사각형과 서로 다른 세 오브젝트의 대상 강조 |
| [360px 도구 막대](../../output/playwright/my-brush-mobile.png) | 텍스트 도구·크기 조절을 포함한 줄 나눔 |
| [360px 설정 창](../../output/playwright/my-brush-shortcuts-mobile.png) | 7개 단축키와 저장·취소 접근 |

임시 검증 과정에서 바꾼 브라우저 설정은 기본값으로 돌렸고 검증용 오브젝트는 새로고침으로 제거했다. 처음 제공하는 샘플 3개만 남긴다.

## 데스크톱 구현에서 확인할 항목

다음은 이 브라우저 시안으로 검증하지 않는다.

- 다른 앱 위 투명 최상위 창과 실제 화면 좌표 대응.
- 일반 앱으로 돌아갈 때 입력 통과와 이전 앱 포커스 복구.
- 전역 단축키 등록, 최초 등록 실패의 대체 진입, OS 점유 조합 충돌.
- macOS Control+왼쪽 드래그와 보조 클릭·컨텍스트 메뉴 처리.
- 다중 모니터, 화면 배율 변경, 전체 화면 앱, 실제 한글 IME.
- Windows 환경 실행, 설치·배포·앱 종료 후 설정 복원.
