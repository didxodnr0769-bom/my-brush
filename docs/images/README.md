# 문서용 앱 캡처

2026-10-28, macOS 26.6.2 arm64에서 실제 패키징된 My Brush 0.2.2를 임시 사용자 설정으로 실행해 촬영했다. 이전 `preview/index.html`이나 생성형 이미지를 사용하지 않았다.

| 파일 | 표시 상태 |
|---|---|
| `overview.png` | 실제 펜 입력으로 만든 굵은 초록 곡선·가는 잉크 곡선·오렌지 강조선 2획과 도구 막대. 텍스트 오브젝트 없음 |
| `area-delete.png` | Control+드래그 영역이 강조선 일부에 닿았을 때 획 전체의 삭제 대상 미리보기 |
| `shortcuts.png` | macOS 기본값을 표시하는 단축키 설정 창 |

Electron `BrowserWindow.capturePage()`로 앱의 투명 레이어만 캡처했다. 문서에서 읽기 쉽도록 투명 부분을 옅은 단색 배경에 합치고 필요한 영역을 잘랐다. 앱의 컨트롤·필기·설정 값은 촬영 결과 그대로다. 실제 바탕화면 위 합성 검증과 구분한다.

개인 바탕화면·업무 자료·계정·절대경로를 포함하지 않으며, PNG는 앱 캡처 결과를 다시 인코딩해 사용한다. 원시 검증 결과는 Git에서 제외하는 `output/electron/`에 보관한다.
