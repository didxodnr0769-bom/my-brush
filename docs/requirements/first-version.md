# My Brush 첫 버전 요구사항

작성일: 2026-10-15

## 목표와 확정 범위

맥과 Windows에서 같은 기능과 사용감으로 사용할 화면 필기 앱을 만든다. ScreenBrush에서 필요한 기능만 구현하며, 기기 사이의 필기·설정 동기화는 현재 목표에 포함하지 않는다.

아래 7개 기능은 사용자가 직접 선택한 첫 버전 범위다. 이 문서는 요구사항 확정 기록이며 데스크톱 앱의 구현 완료 기록이 아니다. 화면·입력 설계와 브라우저 시안은 별도 문서에서 관리한다.

| 요구사항 | 기능 | 필요한 동작 | 기존 조사 항목 |
|---|---|---|---|
| REQ-01 | 화면 위 자유 필기 | 다른 앱 화면 위에서 자유롭게 선을 그릴 수 있음 | DRAW-01 |
| REQ-02 | 선 굵기 변경 | 필기에 사용하는 선 굵기를 변경할 수 있음 | DRAW-05 |
| REQ-03 | 색상 변경 | 화면에 그리거나 표시할 색상을 변경할 수 있음. 구체적인 선택 UI는 상세 설계에서 제안 | COLOR-02, COLOR-04 참조 |
| REQ-04 | 단축키 설정 | 첫 버전에 포함되는 동작의 단축키를 사용자가 설정할 수 있음 | INPUT-02 일부 |
| REQ-05 | 사각형 | 화면에 사각형을 만들 수 있음 | SHAPE-03 |
| REQ-06 | 화면 텍스트와 크기 조절 | 화면에 텍스트를 표시하고 글자 크기를 조절할 수 있음 | TEXT-01, TEXT-02의 크기 부분 |
| REQ-07 | Ctrl+드래그 영역 삭제 | Ctrl을 누른 상태로 드래그하면 사각형 영역을 만들고, 해당 영역과 일부라도 겹친 오브젝트 전체를 삭제 | EDIT-09의 영역 삭제 부분 |

REQ-07의 삭제 조건은 사용자 답변으로 **일부라도 겹치면 오브젝트 전체 삭제**로 확정했다. 영역 안에 완전히 들어와야만 삭제하는 방식은 채택하지 않는다.

## 영역 삭제의 동작 정의

확정한 사용자 요구는 다음과 같다.

1. Ctrl을 누르고 드래그해 사각형 삭제 영역을 만든다.
2. 그 영역과 일부라도 겹친 오브젝트를 대상으로 한다.
3. 겹친 부분만 깎아내는 것이 아니라 해당 오브젝트 전체를 제거한다.

오브젝트를 다음 단위로 관리하는 것은 **삭제 단위 설계 초안**이다. 사용자가 확정한 겹침·전체 삭제 원칙과 구분한다.

| 오브젝트 | 삭제 단위 |
|---|---|
| 자유 필기 | 누르기부터 떼기까지 그린 한 획 전체 |
| 사각형 | 사각형 하나 전체 |
| 화면 텍스트 | 한 번 만든 텍스트 오브젝트 전체. 일부 글자만 영역에 걸려도 오브젝트 전체가 대상 |

다음은 이 요구를 구현하기 위한 **동작 설계**다. 사용자 선택 원칙과 구분하며, 추가 기능 선택으로 보지 않는다. 상세 내용은 [도구 막대와 입력 설계](../design/interaction-design.md)에서 관리한다.

- 드래그 중 삭제 영역을 사각 테두리로 표시하고, 이 테두리 자체는 필기 오브젝트로 저장하지 않는다.
- 드래그 방향에 관계없이 시작점과 끝점으로 사각 영역을 계산한다.
- 마우스 버튼을 놓을 때 영역 삭제를 적용한다. 드래그 도중에는 실제 오브젝트를 지우지 않는다.
- 삭제 작업을 마치면 이전에 선택한 필기·사각형·텍스트 도구로 돌아간다.
- macOS에서도 요구한 키는 Control이다. Command로 바꾸어 해석하지 않는다.
- 교차 판정은 상세 설계에서 펜·사각형의 실제 선 영역과 텍스트의 레이아웃 상자를 기준으로 제안했다. 경계 상자만 겹치는 빈 부분을 구분하는 사례를 검증한다.

## 상세 설계의 기본값

기능 범위는 사용자 선택으로 확정했다. 아래 항목은 [도구 막대와 입력 설계](../design/interaction-design.md)에 제안값을 정리했으며 [브라우저 시안](../../preview/index.html)에서 검토한다. 이 값들은 사용자가 직접 지정한 요구사항과 구분한다.

- 색상은 기본 8색과 직접 선택을 제공한다.
- 선 굵기는 1~32 DIP, 초기 4이며 사각형과 공통 적용한다.
- 텍스트 크기는 12~144 DIP, 초기 28이며 기존 텍스트를 다시 편집해 바꾼다.
- 설정 가능한 단축키 7개와 기본 조합을 제안했다. Ctrl+드래그는 고정 입력으로 둔다. OS 전역 단축키 등록·충돌 검증은 네이티브 구현에서 수행한다.
- 필기 시작·작업 복귀 토글로 화면을 표시·숨기며 세션 안에서 오브젝트를 유지한다. Ghost·Freeze 등 별도 모드 전체를 포함하는 것으로 해석하지 않는다.

## 이번 범위에 포함하지 않은 기능

현재 선택한 것은 위 7개 기능이다. 화살표·직선·타원, 배지·타이머, 확대·Flashlight, 스냅샷·내보내기, 모바일 Remote, Lower Third, 설정 프리셋, 자동 사라짐·Freeze, Undo/Redo·전체 지우기 등은 첫 버전 범위에 자동으로 추가하지 않는다.

사각형의 채움·둥근 모서리, 텍스트의 글꼴·배경·이모지 기능도 선택한 것으로 간주하지 않는다. 이후 사용자가 선택하면 범위를 갱신한다.

## 검증할 사용자 시나리오

구현 후 맥과 Windows에서 다음을 직접 확인한다. 현재는 아직 실행하지 않은 검증 기준이다.

| 대상 | 확인할 동작 |
|---|---|
| 자유 필기 | 다른 앱 위에 한 획을 그리고, 다음 획과 구분되어 관리됨 |
| 굵기·색 | 값을 바꾼 뒤 새로 만드는 표시가 선택값을 사용함 |
| 단축키 | 설정한 조합으로 해당 동작을 호출할 수 있음 |
| 사각형 | 드래그로 사각형 오브젝트를 만들 수 있음 |
| 텍스트 | 텍스트를 표시하고 크기를 조절할 수 있음 |
| 영역 삭제 | 영역 안에 들어온 오브젝트와 경계에 일부만 걸친 오브젝트가 모두 전체 삭제됨 |
| 삭제 제외 | 영역과 겹치지 않는 오브젝트는 유지됨 |
| 복수 삭제 | 한 번의 영역 지정으로 필기·사각형·텍스트 여러 개를 함께 삭제할 수 있음 |
| 임시 표시 | 삭제 영역의 사각 테두리가 일반 사각형 오브젝트로 남지 않음 |
